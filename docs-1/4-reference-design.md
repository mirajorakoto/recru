# Référence de design

Le module reprend seulement les conventions visuelles nécessaires du site public et de l’admin, sans copier les pages métier.

## Public

- fond clair `#f7fbff`, surfaces blanches;
- bleu principal `#0050cb`, bleu secondaire `#0066ff`;
- titres de type Outfit et texte de type Inter, avec fallback système;
- cartes arrondies 24 px, bordures bleues légères, boutons pilules;
- conteneur maximal 1120 px et fonctionnement à partir de 320 px.

## Admin

- fond chaud `#f9f6f0`, surface blanche;
- accent RH `#0d7c66` et texte `#1a1a1a`;
- titres Space Grotesk, corps IBM Plex Sans avec fallbacks;
- tableaux scrollables, panneau latéral de détail et formulaires à deux colonnes puis une colonne mobile.

Le logo fourni est l’actif officiel déjà public. Aucun visuel, donnée ou composant sans rapport direct avec le recrutement n’est inclus.
